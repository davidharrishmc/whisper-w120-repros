# Whisper: an access fault on a page-table-walk access writes the transformed instruction to mtinst/htinst

When the page-table walk for a load, store or AMO takes an access fault on one of its implicit accesses (a PTE read, or
the store that sets A/D, in the S-, VS- or G-stage walk), Whisper writes the transformed load/store/AMO to mtinst or
htinst. Standard transformations are defined only for exceptions that arise from explicit memory accesses
(hypervisor.adoc, `norm:H_trap_xtinst_std_trans_mem`, `norm:H_trap_xtinst_no_trans_zero`), so the value must be 0.

`tinst-ptw.elf` (generated by `gen.py`, built by `build.sh`) is a bare-metal self-checking RV64 test. M-mode sets up
Sv39 and Sv39x4 tables, PMP (entry 0: page 0x80101000 no S/U access; entry 1: page 0x80207000 S/U read-only) and
menvcfg/henvcfg.ADUE = 1 (hardware A/D updates). Each case runs one instruction in S, U or VS mode, the trap goes to M
(medeleg = 0) or to HS, and M-mode checks the cause and the trap-instruction register of the trap's destination
(mtinst for M, htinst for HS) and prints one line per case:

- 19 implicit-access cases (expected 0): S-stage PTE read in the no-access page (ld, sd, amoadd.d, c.lw from S into M
  and HS; ld from U); S-stage A/D update in the read-only page (ld, sd); VS-stage PTE read in the no-access page with
  hgatp Bare (ld, sd into M and HS) and Sv39x4 (ld); VS-stage A/D update in the read-only page; G-stage PTE read in
  the no-access page (vsatp Bare); `hlv.d` from HS whose VS-stage walk reads the no-access page.
- 3 controls: an explicit PMP access fault and an explicit page fault (0 or the transformation 0x00003603), and a
  guest-page fault on a VS-stage PTE read (pseudoinstruction 0x3000, since htval is nonzero).

Run: `./run.sh [path/to/whisper]` (exit status 0 = pass). It runs
`whisper --maxinst 10000000:f --config whisper.json tinst-ptw.elf`; `whisper.json` is the riscv-arch-test
whisper-rv64-max configuration, and `include/rvmodel_macros.h` is its console and halt macros.

Whisper master f1a46baa (`master.out`): the 19 implicit-access cases fail (mtinst/htinst = 0x00003603 for `ld`,
0x00d03023 for `sd`, 0x00d0362f for `amoadd.d`, 0x00002601 for `c.lw`, 0x6c004673 for `hlv.d`); the controls pass.
With the fix (`fixed.out`) all 22 pass.

Other simulators (each built with its riscv-arch-test rv64-max `rvmodel_macros.h`): Spike 020edce and Imperas (an
engineering build after Y-2026.09) pass all 22. Sail 0.16 writes the same values as Whisper. QEMU 11.1.2 writes the
transformed values on the S-stage, A/D-update, G-stage and HLV cases; a VS-mode load or store whose VS-stage walk reads
a PMP-denied PTE takes no trap there.
